À propos de CycloStats

Le projet

CycloStats est une application Django open-source qui agrège et présente les données du cyclisme professionnel issues de procyclingstats.com via la bibliothèque Python pcs-scraper.

Fonctionnalités
  • Profils détaillés de coureurs avec historique de carrière
  • Résultats complets de toutes les courses UCI
  • Données d'équipes avec effectifs
  • Classements individuels et par équipes
  • Comparaison entre coureurs
  • Calendrier des courses
  • API REST complète
